- Selected work
- Data and web experience interests

- `styles.css` - Responsive layout, typography, colors, and visual styles

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any local web server:

```text
personal-portfolio/
  index.html
  styles.css
```
